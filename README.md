# TaskManager Web

## Descripción
TaskManager Web es una aplicación web que permite organizar actividades personales mediante una lista de tareas. Su objetivo es facilitar el seguimiento de actividades pendientes y completadas.

## Objetivo
Desarrollar una aplicación sencilla utilizando HTML, CSS y JavaScript, aplicando el control de versiones con Git y GitHub.

## Tecnologías utilizadas
- HTML5: estructura de la aplicación.
- CSS3: diseño y estilos responsivos.
- JavaScript: funcionamiento e interacción.
- Git: control de versiones.
- GitHub: almacenamiento remoto del proyecto.

## Funcionalidades
- Agregar nuevas tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Consultar estadísticas de tareas totales, pendientes y completadas.
- Guardar tareas en el navegador mediante LocalStorage.
- Conservar las tareas al actualizar la página.
- Adaptar la interfaz a dispositivos móviles.

## Requisitos
- Navegador web actualizado.
- Git instalado (para trabajar con el repositorio).

## Instalación y ejecución
1. Descargar o clonar el repositorio.
2. Abrir la carpeta TaskManager-Web.
3. Ejecutar el archivo `index.html` en un navegador.
4. Comenzar a agregar y administrar tareas.

## Flujo de trabajo con Git
Se utilizaron las siguientes ramas:
- `main`: versión principal del proyecto.
- `feature/interfaz`: mejoras de interfaz y accesibilidad.
- `feature/tareas`: funcionalidades y almacenamiento de tareas.
- `feature/estilos`: mejoras visuales y adaptación móvil.

Las modificaciones se registraron mediante commits y se prepararon para integrarse a la rama principal mediante Pull Requests.
